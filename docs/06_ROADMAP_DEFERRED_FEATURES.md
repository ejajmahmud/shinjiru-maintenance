# Shinjiru Maintenance - Future Roadmap

Following the product principle of shipping a clean, reliable, and finished initial release (v1.0.0), advanced complex features requiring external integrations or dedicated backend databases were deliberately deferred to ensure maximum stability and zero privacy vulnerabilities.

---

## 1. Planned for Version 1.1.0
- **Native Subscriber Capture (Opt-in Lead Gen):**
  - Self-hosted database table for pre-launch subscriber capture.
  - Double opt-in email verification option.
  - CSV subscriber export with privacy compliance (GDPR consent checkbox).
- **Social Media Icons Expansion:**
  - Expanded icon collection for Threads, Bluesky, TikTok, and Discord.

## 2. Planned for Version 1.2.0
- **Network-Wide Multisite Management:**
  - Centralized network dashboard for multisite super-admins to toggle maintenance across all sub-sites simultaneously.
  - Per-site overrides for individual network site owners.
- **Granular URL Whitelist & Blacklist:**
  - Capability to enforce maintenance mode only on specific URL patterns or post types (e.g., locking checkout during catalog updates).

## 3. Planned for Version 1.3.0
- **Webhook Status Notifications:**
  - Webhook dispatch on maintenance activation / deactivation to Slack, Microsoft Teams, or custom developer URLs.
